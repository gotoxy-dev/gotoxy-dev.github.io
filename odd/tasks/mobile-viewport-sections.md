Branch: feat/instituto-cam-case. Delivery: ask-on-risk. Runner: no unit runner; `npm run build` + browser checks at 375×812 and 390×844 (and a short viewport, 375×667).

Earlier phone decisions in `odd/tasks/mobile-alignment.md` stand unless they conflict with S1–S2 (then report the conflict).
